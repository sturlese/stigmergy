What staged replication means in the Quillon Labs work

The term "staged replication" keeps coming up in conversations with Quillon Labs and it means
something specific there that it does not mean elsewhere, so it is worth pinning down before
somebody uses it loosely in a document.

In the Quillon context, staged replication is the practice of reproducing a result in deliberate
steps of increasing independence, rather than repeating the same experiment. The first stage
repeats the work with the same materials and the same people, which only catches transcription
mistakes. The second stage repeats it with the same materials and different people, which
catches technique that was never written down. The third stage repeats it with materials sourced
independently, which is the only stage that catches a problem in the materials themselves.

The point of the ordering is economic. Each stage costs meaningfully more than the one before,
and each catches a class of error the earlier stages structurally cannot. Running the third stage
first would be more rigorous and is what people assume rigour looks like, but it spends the
expensive check on failures a cheap one would have found.

Why it matters to us: when Quillon says a result is replicated, the useful follow-up question is
which stage, not whether. A result replicated at the first stage and a result replicated at the
third are both honestly described as replicated and mean very different things about how much
weight the result can carry.

Where it gets misused: people outside Quillon hear "replicated" and assume the third stage,
because that is the everyday meaning of the word. Quillon does not do this deliberately — the
staged sense is simply the house usage — but the misreading is common enough that it is worth
asking every time rather than assuming.

The related idea worth not confusing this with is repetition for statistical power, which is
about running the same stage more times. Staged replication is about running different stages,
and more repetitions of stage one never add up to a stage three.
