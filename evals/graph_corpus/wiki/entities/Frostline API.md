# Frostline API

## What / Who

The Frostline API is [[Tidewell]]'s interface through which customers can pull their data. (Source: `sources/2026/01/60e59b80-2e07-52cb-9a03-a4b3d40e34fd.md`)

## Facts

- 2026-01-08: described as the API customers can use to pull data.

(Source: `sources/2026/01/60e59b80-2e07-52cb-9a03-a4b3d40e34fd.md`)

- 2026-07-02: [[Sabine Krüger]] confirmed it can push excursion events to [[Stratos ERP]], and that [[Tidewell]] is talking to [[Stratos Software]] about a certified connector.

(Source: `sources/2026/07/c54967da-3d89-5c8d-b202-c1056f8f92e4.md`)

- 2026-07-14: [[Tidewell]] agreed with [[Stratos Software]] to build a certified Stratos connector on top of it, attaching excursion events and Good Distribution Practice reports to the matching shipment record in [[Stratos ERP]].

(Source: `sources/2026/07/e17d5404-01e2-535c-8c1a-a03bf0d45a03.md`)
